# Python Portfolio & Automatisierungs-Skripte

Willkommen in meinem GitHub-Repository! Hier sammle ich verschiedene Python-Skripte und Automatisierungsprojekte, die ich im Rahmen meiner Lernreise entwickelt habe.

## 📁 Enthaltene Skripte

* **`wurf.py`** – Ein interaktiver Würfel-Simulator, der Zufallszahlen generiert und statistische Auswertungen über die Würfe liefert.
* **`roboter.py`** – Ein Skript zur zufälligen Roboter-Auswahl für logistische Prozesse.
* **`robot_logic.py`** – Eine eigenständige Logik-Steuerung für die automatisierte Paket-Sortierung.
* **`log_checker.py`** – Ein robustes Logfile-Analyse-Tool, das Testdaten automatisch generiert und detaillierte statistische Berichte auswertet.

## 🛠️ Verwendete Technologien & Konzepte
* **Python** (Modul `random`, Datei-I/O, Funktionen)
* Datenstrukturen: **Listen** und **Wörterbücher (Dictionaries)**
* Versionsverwaltung mit **Git & GitHub**
